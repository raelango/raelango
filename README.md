### What I'm building
 
**[medikode-mcp-server](https://github.com/raelango/medikode-mcp-server)**
Model Context Protocol server that brings Medikode's medical-coding tools (code validation, chart QA, EOB parsing, RAF scoring) into Claude, Cursor, and ChatGPT. Published on npm as `@medikode/mcp-server`.
 
**[medikode-agents](https://github.com/raelango/medikode-agents)**
Stage definitions and Claude Code skills for Medikode's multi-agent pipelines: chart-to-claim coding, audit reconciliation, remittance-to-EDI 835, risk adjustment, and NCCI compliance checks.
